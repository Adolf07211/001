# 配置说明

## whale_wake.json

放在 `AstrBot/data/whale_wake.json`：

```json
{ "group_reply_threshold": 15, "wake_on_unknown_reply": true }
```

- `group_reply_threshold`：群里连续多少条消息没 @ 她时，她插一句。**值越小越活跃，也越容易被风控**
- `wake_on_unknown_reply`：有人引用/回复她时不认识时也当作被叫

## platform_settings 关键项

在 AstrBot 面板「配置」里改，或直接改 `data/cmd_config.json`：

```json
{
  "segmented_reply": {
    "enable": true,
    "interval_method": "log",
    "log_base": 2.6
  },
  "reply_with_mention": true
}
```

- `interval_method: "log"`：分段回复的间隔按字数算，`y = log(2.6, x)` 秒
- `reply_with_mention`：回复时 @ 对方

## 插件内的开关（main.py 顶部）

```python
QZONE_WATCH_ENABLED = False     # 空间自动回评/回@
STICKER_PROBABILITY = 0.5       # 自动发表情概率
FOLLOWUP_GROUP_ENABLED = False  # 群聊主动搭话
```

## 环境变量

| 变量 | 作用 |
|---|---|
| `WHALE_TARGET_UIN` | 空间巡检的目标 QQ（你自己） |
| `WHALE_VIEWERS` | 能用 `/记忆` `/日记` 的 QQ，逗号分隔 |
| `WHALE_FOLLOWUP_SPEED` | 主动搭话加速倍率，测试用 |
